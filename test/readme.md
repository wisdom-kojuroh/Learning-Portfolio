ファイルのエクスポートからインポート、そして画面に反映されるまでの全体的な流れ。

🔄 ファイルIO（エクスポート・インポート）の完全な流れ
1. 【エクスポート（書き出し）のフェーズ】
アプリ内データの収集

現在ローカルストレージやメモリ上で管理しているアプリのデータ（タスク、設定、ノートなど）を JavaScript のオブジェクトや配列としてかき集める。

JSON文字列への変換

集めたデータを JSON.stringify(data, null, 2) などを使って、綺麗にフォーマットされた JSON 文字列に変換する。

Blobオブジェクトの生成

その JSON 文字列をラップして、ブラウザ上でファイルとして扱えるように new Blob([jsonString], { type: 'application/json' }) で Blob を作る。

ダウンロード用リンクの動的生成と発火

URL.createObjectURL(blob) で一時的な URL を発行し、隠しリンク（<a> タグ）をプログラムから一時的に生成して click() メソッドを自動実行させることで、ユーザーのデバイスにファイルをダウンロードさせる。

メモリの解放

処理が終わったら URL.revokeObjectURL() を呼んで、ブラウザが保持していた一時URLのメモリをキレイに解放する。

2. 【インポート（読み込み）のフェーズ】
ファイルの選択

ユーザーが <input type="file" accept=".json"> を使って、デバイス内にあるバックアップ用の JSON ファイルを選択する。

FileReaderでの読み込み

FileReader API（または file.text() などのモダンな非同期メソッド）を使って、選択されたファイルのデータをテキスト（文字列）として読み込む。

JSONのパース（箱への展開）

読み込んだ文字列を JSON.parse() でJavaScriptのオブジェクトに戻し、アプリが受け入れられる「箱（データ構造）」の形にしっかり合致しているか確認する。
(※ここでデータの型や必須項目チェック・バリデーションを挟むとさらに安全！)

データの永続化（ストレージへの保存）

パースして取り出したデータを、localStorage や IndexedDB などのストレージに上書きまたはマージして保存し、ブラウザを閉じてもデータが消えないようにする。

UIの再描画（画面の更新）

ストレージの保存完了後、アプリ内の描画関数を呼び出して画面（DOM）をリフレッシュし、新しく読み込まれたデータがリアルタイムで画面に反映されるようにする。
